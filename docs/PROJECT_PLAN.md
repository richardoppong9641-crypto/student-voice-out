# Student Voice Out — Project Plan

## Vision

Build a secure, modern student platform where students can express their voices, access useful information and support, discover opportunities, connect with organizations, and participate in positive change.

## Initial modules

1. Landing page and public information
2. Student registration and secure login
3. Student profile
4. Persistent Student Voice Out member ID
5. Student dashboard
6. Welfare and support
7. News and updates
8. Posts and videos
9. Events
10. Opportunities
11. Partners and organization access
12. Sub-organizations
13. Notifications
14. Administration and moderation
15. Security, privacy, and audit controls
16. Sustainability and monetization

## Development principles

- Build in small, testable stages.
- Keep the project source organized.
- Preserve major versions in Git history.
- Do not expose passwords, secrets, API keys, or private credentials in source code.
- Test important user flows before calling a feature complete.
